# ЭкоНорма BY

Учебный проект по ЛЭС: стартап-идея и лендинг в формате задания, образец которого был прислан в файлах `7 вопросов.docx`, `оформлерние потом.docx`, `СВОТ.docx`, `СВОТ — копия.docx`.

**Авторы:** Токарь Глеб Максимович, Христич Даниил Андреевич.

**Идея.** SaaS-сервис для цифрового учёта отходов и подготовки к проверкам Минприроды для малого и среднего бизнеса Беларуси. Вместо бумажных журналов ПОД-9/ПОД-10 и разрозненных Excel-файлов — встроенный классификатор отходов, автоматические акты, Telegram-бот с напоминаниями и «индекс готовности к проверке» в личном кабинете.

**Почему эта сфера.** На 01.01.2026 в РБ — 135 тыс. организаций МСБ и 204,4 тыс. ИП; Минприроды ежегодно выявляет более 50 тыс. нарушений; штрафы по ст. 16.44 КоАП РБ доходят до 500 БВ (22 500 BYN) для юрлиц. 30.09.2026 принято новое постановление № 31 «Об обращении с отходами» — свежий регуляторный триггер для продукта.

## Состав репозитория

| Путь | Что это |
| --- | --- |
| `index.html` | Лендинг продукта: проблема, решение, демо, тарифы, рынок, SWOT, источники |
| `reshenie.html` | Полное решение задания в веб-виде (7 вопросов + исследование рынка + SWOT) |
| `assets/styles.css`, `assets/app.js` | Стили и интерактив (чек-лист готовности, счётчики, меню) |
| `документы/7 вопросов.docx` | Ответы на 7 вопросов |
| `документы/оформлерние потом.docx` | Исследование рынка, TAM / SAM / SOM, расчёт по Витебску |
| `документы/СВОТ.docx` | SWOT-анализ (таблица 1.3) |
| `документы/СВОТ — копия.docx` | Рабочая копия SWOT-анализа |
| `РЕШЕНИЕ.md` | То же решение в Markdown — удобно читать и копировать |
| `tools/generate_docs.py` | Скрипт, который пересоздаёт все 4 файла `.docx` |

## Запуск локально

Статический сайт без сборки — достаточно любого HTTP-сервера:

```bash
cd eko-norma
python3 -m http.server 8000
# открыть http://localhost:8000
```

Перегенерация документов (нужен `python-docx`):

```bash
pip3 install python-docx
python3 tools/generate_docs.py
```

## Цифры модели

- Средний чек: **240 BYN/год** (20 BYN/мес)
- **TAM:** 135 000 × 240 = 32,4 млн BYN/год
- **SAM:** 53 120 × 240 = 12,75 млн BYN/год
- **SOM (3% за 3 года):** 1 594 клиента × 240 = 383 тыс. BYN/год
- Пилот, Витебск: 1 440 организаций → SAM ≈ 346 тыс. BYN/год, SOM ≈ 10 тыс. BYN/год
